# Product Images

Drop your product photos here and reference them in `index.html`.

## Recommended sizes

| Use                  | Size       | Format       |
|----------------------|------------|--------------|
| Hero image           | 960 × 1200 | JPG / WebP   |
| Gallery items        | 800 × 600  | JPG / WebP   |
| Product card images  | 600 × 450  | JPG / WebP   |

## How to use an image

Replace any placeholder block in `index.html` with an `<img>` tag:

```html
<!-- Before (placeholder) -->
<div class="hero-img-placeholder">...</div>

<!-- After (real image) -->
<img src="assets/images/hero-collection.jpg" alt="Signature Collection 2025">
```

## Tips

- Keep file names lowercase with hyphens: `custom-hoodie-black.jpg`
- Compress before uploading — aim for under 200 KB per image
- Use WebP for best performance; JPG as fallback
